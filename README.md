# phishing-detector

Uma ferramenta inteligente para detectar e analisar URLs suspeitas de phishing usando análise de padrões e validação de segurança.

## 🎯 Objetivo

Fornecer uma solução eficaz para identificar tentativas de phishing através da análise de características de URLs, incluindo:
- Análise de domínio
- Detecção de URLs encurtadas suspeitas
- Verificação de certificados SSL
- Análise de padrões de texto
- Scoring de confiabilidade

## ✨ Recursos

- Análise em tempo real de URLs
- Detecção de padrões comuns de phishing
- Verificação de reputação de domínio
- Interface simples e intuitiva
- Relatórios detalhados de análise
- API REST para integração

## 🚀 Quick Start

### Requisitos
- Python 3.8+
- pip ou conda

\\\ash

cd phishing-detector
pip install -r requirements.txt
